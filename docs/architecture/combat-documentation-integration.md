# Consulta normativa del motor de combate

El [SRD 3.5 en Markdown](../../INDEX.md#srd-35-en-markdown) es la referencia local para el texto abierto de las reglas. Los NDD y ADR fijan las decisiones de implementación, incluidas las divergencias aprobadas. La [auditoría normativa](../audits/combat-rules-deviations.md) conserva las diferencias conocidas y su contexto.

El [Rule Registry](../rules/registry.md) vincula cada Rule ID con el SRD, su diseño, implementación y pruebas. La [matriz de cobertura](../testing/master-coverage.md) registra evidencia ejecutada. Al cambiar una regla, seguí la política de actualización de [AGENTS.md](../../AGENTS.md#verificación-y-cierre).

Los archivos de [combate](../../combat/00_indice.txt) se conservan para las referencias históricas al capítulo 8. Para una consulta nueva, partí de la sección SRD enlazada por el Registry y consultá el NDD vigente para el comportamiento del motor.
